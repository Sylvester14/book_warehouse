# Book warehouse

Репозиторий содержит преднастроенное Docker-окружение для быстрого тестового запуска

---

## 🚀 Быстрый запуск проекта

Выполните эти команды пошагово в терминале из корневой папки проекта:

### 1. Сборка Docker-образа
Соберите конфигурацию проекта:
```bash
docker compose build
```

### 2. Запуск контейнеров
Запустите все сервисы в фоновом режиме:
```bash
docker compose up -d
```

### 3. Применение миграций базы данных
Создайте необходимую структуру таблиц в базе данных внутри контейнера `web`:
```bash
docker compose exec symfony php bin/console doctrine:migrations:migrate --no-interaction
```

### 4. Загрузка тестовых данных
Наполните базу данных демонстрационными данными для тестирования:
```bash
docker compose exec -T database psql -U app -d book_warehouse_db < data/dump.sql  
```
